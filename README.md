## 如何打开

进入存档后：

1. 左下附近的 **管理 / ADMIN** 按钮（可在设置里关闭或改位置）  
2. 右键地面 → 管理员菜单  
3. 热键（默认 **F6**，可在设置里改为 F7/F8/F9）

## 安装

将整个 `SimpleAdminMenu` 文件夹放到：

```
C:\Users\你的用户名\Zomboid\mods\SimpleAdminMenu
```

在游戏 Mods 菜单中启用 **简易管理员菜单**。

Build 42 会读取 `42/` 目录；Build 41 仍会读取根目录 `media/`。
